## Multron Win Cleaner Database Update

### App categories
- Every app section now says which group it belongs to, as the last part of its first line, for example `{=Spotify=category:media` or `{=Discord=app=discord.exe=category:communication`.
- 619 sections have a category: 121 Internet & Communication, 98 Media & Graphics, 62 Office & Productivity, 91 Development, 100 Games, 22 Security, 123 System Tools and 2 Browsers (Safari for Windows and Biscuit, which are not tagged as `browser`).
- Windows sections and the sections tagged `browser` have no category, because the app already knows where they belong.
- Multron Win Cleaner 1.29 uses the categories to sort Cleaning Selections into Browsers, Internet & Communication, Media & Graphics, Office & Productivity, Development, Games, Security and System Tools. Because the group comes from the database, an app is in the same group on every PC.

### Checks
- `scripts/validate-database.js` accepts the category at the end of a section line, refuses unknown categories and a category that is not the last part of the line.
- The README explains how to give a new section a category.

### Older versions of the app
- Older versions ignore the category, so this database works with them as before.
- Multron Win Cleaner 1.29 needs this database to sort the apps: with an older database it shows every app under Other Applications.
