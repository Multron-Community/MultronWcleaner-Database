## Multron Win Cleaner Database Update

### Browser and app tags
- The 65 web browser sections are now marked as browsers, with the name of the browser's program, for example `{=Google Chrome=browser=chrome.exe`.
- 35 apps that keep their cache locked while they run are marked as apps, for example `{=Discord=app=discord.exe`: Discord, Slack, Microsoft Teams, Spotify, Telegram, WhatsApp, Zoom, Signal, Visual Studio Code and more.
- Multron Win Cleaner 1.27.4 and later use these tags to see whether the browser or app is open before cleaning it, and ask you to close it so that all of its files can be cleaned.
- Microsoft Edge WebView2 is not marked: other apps use it, so closing it would close them too. Tor Browser is marked without a program name, because it runs as `firefox.exe` and would be mixed up with Firefox.

### Warnings on risky entries
- The 15 entries of **Windows User Folders** and **Windows System Files (Advanced)** that delete your own files or files Windows needs now carry a warning, for example `Downloads=C:\Users\{##}\Downloads=false=Your own downloaded files are deleted`. They stay off by default.
- Every entry that deletes personal data carries a warning too: saved passwords, cookies, history, open tabs and sessions, form and payment data, website data, extension data and program settings (about 1,200 entries, most of them in browser profiles). None of them is on by default.
- Multron Win Cleaner shows the warning next to the entry and, from 1.27.4, asks for confirmation before cleaning any of them.

### Why an entry is not on by default
- Every entry that is off by default and had no warning now says why, either as a warning (for example *Deletes your game saves*, *Programs need these files to repair, update or uninstall themselves*) or as an info note that starts with *Not selected by default:* (for example *logs help to find the cause of problems*). Every one of the 2,349 entries that are off by default now has a note.

### Older versions of the app
- Older versions only read the section name and ignore the new tags, so this database works with them as before. They already show entry warnings.
