## Multron Win Cleaner Database Update

The database is now organized by component and category, and it has 168 new cleaning entries: 27 new apps and tools, and new areas for 32 apps that were already listed. No existing entry was changed or removed, so your saved selections still apply.

### Windows is split into components
The large **Windows** group is now split into separate groups, so each part of Windows can be checked on its own:
- **Windows Temporary Files**, **Windows Recycle Bin**
- **Windows Update**, **Windows Delivery Optimization**, **Windows Upgrade Leftovers** (Windows.old, $Windows.~BT and other setup folders), **Windows Component Store & Servicing** (CBS, DISM and WinSxS)
- **Windows Installer & Package Caches**, **Windows Error Reporting & Crash Dumps**, **Windows Logs**
- **Windows Thumbnail & Icon Cache**, **Windows Font Cache**, **DirectX Shader Cache**, **Windows System Caches**, **Windows Search**, **Windows Widgets**
- **Microsoft Defender** (the two Defender groups are now one), **Windows User Folders** (Downloads, Screenshots and Captures) and **Windows System Files (Advanced)** for the page file, hibernation file, restore points and other items that are off by default.

### Groups are sorted by category
All groups now appear in a fixed order: Windows, Microsoft Store apps, web browsers, communication, office, developer tools, AI apps, graphics and video, media, game launchers, games, emulators, security, utilities, cloud storage, remote access and VPN, downloads and torrents, virtualization, drivers and hardware, PC manufacturer apps, and legacy software. Inside each category the groups are in alphabetical order. Group names such as `GoogleChrome` now read as `Google Chrome`.

### More space from update caches
Many apps keep a full copy of their last installer after updating. These copies are now cleaned:
- **Pending app updates** for Bitwarden, LM Studio, Google Antigravity, OpenCode, Signal and Obsidian. On the test PC these four folders alone held 1.3 GB.
- **Old update packages** for Slack, Microsoft Teams Classic, Postman, Figma, WhatsApp, Discord PTB, Discord Canary, Discord Development, Element, GitKraken, Insomnia and Logseq.
- **Browser updaters:** Google Update and the new Google Updater (download cache and log), Brave Update downloads, the Edge updater temporary folder, and Firefox update downloads (off by default).
- **Microsoft Office** update downloads (off by default).

### New apps and tools
- **AI coding tools:** Claude Code (shell snapshots, logs and caches; sessions and file checkpoints are off by default), OpenAI Codex CLI, Gemini CLI, Continue, Trae IDE, Positron IDE and ComfyUI Desktop.
- **Developer tools:** Bazel, Conan, ccache, sccache, GHCup, Yarn Berry cache, pyenv-win downloads, gopls and goimports caches, Android SDK system images (off by default) and Rancher Desktop.
- **Apps and games:** BiglyBT, darktable, dupeGuru, ReplayWeb.page, Exodus (caches only, never wallet data), Lightshot, Qt app shader cache, Synology Drive Client, Sandboxie-Plus (off by default), Spybot Search & Destroy, HP OMEN Gaming Hub, Mozilla Maintenance Service, FACEIT, Blitz, DDNet and Teeworlds, and Grand Theft Auto V Enhanced crash logs.
- **New locations for existing apps:** the current Proton VPN app, TeamSpeak 6, Roblox installer files, Rockstar Games Launcher crash logs and service logs, Apple device crash logs and the Whisper speech model cache (off by default).

### How the paths were checked
- 39 of the new paths were checked on a real Windows 11 installation where the app is installed.
- The others come from the app's own documentation or its standard Electron and Squirrel folder layout. If one of them is wrong for an app version, it is simply not shown, because the app only lists paths that exist.
- Every path was checked so that it does not repeat an existing entry.
- Settings, passwords, cookies, local storage, chat history, saved games, models and wallet data are never cleaned by default.
- Paths that do not exist on a PC are not shown in the list.
