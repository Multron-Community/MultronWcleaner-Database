## Multron Win Cleaner Database Update

This release has the same cleaning entries as v1.14. It is the first **signed** database release.

### Signed database
- The release has an `update.json` with the version and the SHA-256 of `database.txt`, signed with the database release key (`update.json.sig`).
- Multron Win Cleaner 1.26.5 and later only use a database whose signature and SHA-256 match, so a changed `database.txt` is never cleaned with.
- Older versions of the app keep downloading `database.txt` as before.

Check the file yourself with `node scripts/verify-update.js update.json update.json.sig database.txt` from this repository.
